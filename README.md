Скрипт для проверки подписчиков сообщества ВКонтакте на удалённые и заблокированные страницы.

Скрипт собирает ID всех участников через groups.getMembers, проверяет их через users.get и сохраняет подробный отчёт в CSV.

Возможности:

1. Получение полного списка участников сообщества
2. Поиск удалённых страниц
3. Поиск заблокированных страниц
4. Поиск профилей без аватарки
5. Сохранение отчёта в CSV
6. Работа с большими сообществами через пагинацию

Токен и ID группы передаются через переменные окружения

Требования:

1. Python 3.10+
2. Библиотека requests
